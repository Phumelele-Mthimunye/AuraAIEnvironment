# Aura Engineering Brain

This folder contains the living memory of the project.

Its purpose is to allow any AI assistant or engineer to immediately understand:

- what this repository is
- what architecture it follows
- what has already been completed
- what still needs to be built
- what decisions have been made
- what should be worked on next

Every major feature implementation should update the appropriate brain documents.

This folder is the single source of truth for project state.

The brain should always be read before making engineering decisions.

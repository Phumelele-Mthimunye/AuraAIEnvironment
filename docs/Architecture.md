# Aura AI Environment Architecture


## Vision

Aura AI Environment is an AI-assisted software engineering platform.


Its purpose is to allow AI agents to design, build, test and deploy production software.


---

# Core Layers


## Knowledge Layer

Contains:

- Engineering rules
- Agent roles
- Development workflows


## Agent Layer

Contains specialist AI workers:

- Architect
- Backend
- Frontend
- Database
- DevOps
- Security
- Reviewer


## Template Layer

Contains reusable production architectures.


## Execution Layer

Future:

- Ollama models
- Local AI agents
- GitHub integration
- Development tools
